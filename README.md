# Автономная сортировка гуманоидным роботом

Личный заказной проект. Гуманоид Tiangong Pro на ROS 2 распознаёт предметы на столе и переносит их в назначенные лотки. **Результат в симуляторе — 6 из 6 предметов в правильных лотках.**

## Возможности

- **Распознавание по RGB-D.** Камеры головы и корпуса измеряют положения и габариты предметов, столешницу и лотки. По этим измерениям планировщик рассчитывает движения для текущей раскладки.
- **Выбор руки и очереди.** Планировщик учитывает доступ к предмету. Если первый подход недоступен, он пробует другую руку и может вернуться к предмету после основного прохода.
- **Хваты по форме предмета.** Цилиндры захватываются одной рукой, коробка переносится с опорой второй, гибкий кабель подхватывается пальцами. Для мыши и других низких предметов предусмотрены боковой сдвиг к свободному участку, подача на принимающую ладонь и двуручный перенос.
- **Планирование во время движения.** Расчёт следующих маршрутов идёт параллельно с текущей операцией. Там, где геометрия позволяет, скрипт совмещает поворот корпуса с движением рук.
- **Контроль движений и измерение времени.** Планировщик учитывает пределы суставов и геометрию робота и стола. Контроллер читает энкодеры и усилия кистей. Журнал записывает этапы и их длительность по часам симуляции.

## Запуск

Нужны ROS 2 Humble, запущенный симулятор Tiangong Pro, его пакет `bodyctrl_msgs`, а также `cv_bridge` и `message_filters`. Запускайте из той же ROS-среды, где доступны камеры, команды приводов и `/clock`. Python должен видеть ROS-пакеты и OpenCV.

```bash
source /opt/ros/humble/setup.bash
python3 -m pip install -r requirements.txt
bash run.sh --log sort.jsonl
```

Для запуска только одного предмета на текущей сцене можно передать `--only mouse`. Вся сортировка запускается командой без `--only`.
